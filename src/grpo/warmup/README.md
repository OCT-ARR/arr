# 🔥 Warm-up GRPO

🌱 This folder contains the first GRPO stage after SFT. It trains from
`checkpoints/sft_merged` using two rewards:

- format reward for the required `<think>...</think><response>...</response>`
  structure;
- outcome reward from the local MLLM judge.

This stage produces a local LoRA checkpoint under `checkpoints/warmup_grpo/`.
After selecting a checkpoint, merge it into `checkpoints/warmup_merged/`; that
merged model is the initialization for the full FACES GRPO stage.

## 📁 Files

| File | Purpose |
| --- | --- |
| `run_warmup_grpo.sh` | Recommended launcher with repository-relative paths |
| `train_warmup_grpo.py` | Manual GRPO trainer for format + outcome warm-up |
| `merge_warmup_lora.py` | Merge a selected warm-up LoRA checkpoint into the SFT model |
| `test_warmup_model.py` | Local qualitative comparison between SFT and Warm-up models |

## 📦 Required Local Assets

Prepare these paths from the repository root:

```text
checkpoints/sft_merged/
data/MESC-FT/train.jsonl
data/MESC-FT/val.jsonl
keyframes/
models/Qwen3-VL-8B-Instruct/
```

`checkpoints/sft_merged/` is generated by the SFT merge script. The Qwen3-VL
judge model is a public external model and is not included in this repository.

## 🚀 Train

Run from the repository root:

```bash
CUDA_VISIBLE_DEVICES=0,1 PYTHON_BIN=python bash src/grpo/warmup/run_warmup_grpo.sh
```

The launcher expands to:

```bash
python src/grpo/warmup/train_warmup_grpo.py \
  --base_model_path checkpoints/sft_merged \
  --reward_model_path models/Qwen3-VL-8B-Instruct \
  --train_file data/MESC-FT/train.jsonl \
  --val_file data/MESC-FT/val.jsonl \
  --checkpoint_dir checkpoints/warmup_grpo \
  --policy_device cuda:0 \
  --reward_device cuda:1 \
  --temperature 1.3 \
  --top_p 0.95 \
  --max_new_tokens 192 \
  --max_frames 16 \
  --reward_temperature 0.0 \
  --reward_max_new_tokens 512
```

Default settings include batch size `32`, group size `4`, `3` epochs, learning
rate `1e-5`, LoRA rank/alpha/dropout `8/32/0.05`, KL beta `1e-3`, clip epsilon
`0.2`, rollout decoding with temperature `1.3` and top-p `0.95`, rollout max
tokens `192`, maximum video frames `16`, reward-judge max tokens `512`, and
maximum sequence length `1024`. Evaluation/checkpointing runs every `5` steps.
Validation uses the full validation split by default; use
`--val_max_samples N` only for local smoke tests.

## 🔗 Merge

Choose the highest `val_avg_reward` entry in
`checkpoints/warmup_grpo/best.txt`. Replace `<step>` below with the selected
checkpoint step before running the merge.

```bash
python src/grpo/warmup/merge_warmup_lora.py \
  --checkpoint-dir "checkpoints/warmup_grpo/checkpoint-step-<step>" \
  --base-model-path checkpoints/sft_merged \
  --output-dir checkpoints/warmup_merged
```

## 📊 Evaluate

```bash
python src/grpo/warmup/test_warmup_model.py
```
